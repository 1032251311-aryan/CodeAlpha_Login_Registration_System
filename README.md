
# CodeAlpha Login and Registration System

## Project Overview
This project is a simple Login and Registration System developed using C++. It allows users to register with a username and password and log in using their registered credentials.

## Features
- New user registration
- Username and password input
- Duplicate username validation
- File handling to store user credentials
- Login authentication
- Invalid username or password detection
- Exit option

## Technologies Used
- C++
- File Handling
- Functions
- Conditional Statements
- Loops

## How to Run

1. Download or clone this repository.
2. Open the project in a C++ compiler or IDE.
3. Compile the main.cpp file.
4. Run the generated executable.
5. Select an option from the menu.

## Menu Options
1. Register
2. Login
3. Exit
